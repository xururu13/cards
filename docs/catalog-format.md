# Свой набор карточек (YAML)

Набор — это текстовый файл `.yaml`: учебник, разбитый на главы и параграфы, в каждом
параграфе — пары «термин: определение». Приложение загружает его без пересборки:
**«Новая стопка» → «Наборы карточек» → «Загрузить из файла»**.
Файл можно положить в «Загрузки», на Google Диск или прислать себе в мессенджере.

Наборы загружаются из файла или через **«Наборы карточек» → «Импорт из онлайн-каталога»**.
Готовый набор и полный пример формата — биология 7 класса: [catalog/biology-7-pasechnik.yaml](catalog/biology-7-pasechnik.yaml).

Для публикации загрузи YAML в папку `sets/` в [репозитории каталога](https://github.com/xururu13/cards-catalog/tree/main/sets).
GitHub Actions проверит файл, обновит список и выложит набор на [GitHub Pages](https://xururu13.github.io/cards-catalog/).
Для обновления опубликованного набора сохрани прежний `id`.

## Пример

```yaml
id: algebra-7
title: Алгебра. 7 класс
source: По учебнику Макарычева
frontLang: ru
backLang: ru
chapters:
  - title: Глава 1. Выражения, тождества, уравнения
    sections:
      - number: 1
        title: Выражения
        cards:
          Числовое выражение: Запись из чисел, знаков действий и скобок.
          Выражение с переменными: Выражение, в котором есть буквы — переменные.
      - number: 2
        title: Тождества
        cards:
          Тождество: Равенство, верное при любых значениях переменных.
          "(a + b)²": "a² + 2ab + b²"
```

## Поля

| Поле | Нужно? | Что это |
|---|---|---|
| `id` | желательно | Постоянное имя набора латиницей, например `algebra-7`. Файл с тем же `id` заменяет прежнюю версию. Без `id` имя берётся из `title` |
| `title` | да | Название набора, видно в списке |
| `source` | нет | Подпись под названием: учебник, автор |
| `frontLang`, `backLang` | нет | Язык диктовки термина и определения: `ru` или `en`. По умолчанию `ru` |
| `chapters` | да | Список глав |
| `chapters[].title` | да | Название главы |
| `chapters[].sections` | да | Список параграфов главы |
| `sections[].number` | нет | Номер параграфа, показывается как «§5». Можно не писать, например для модулей английского |
| `sections[].title` | да | Название параграфа |
| `sections[].cards` | да | Пары `термин: определение` |

Для английского: `frontLang: en`, термин — английское слово, определение — перевод.

## Правила YAML, на которых чаще всего ошибаются

- **Отступы — только пробелы**, по два на уровень, как в примере. Табуляция не работает.
- **Двоеточие с пробелом внутри текста** ломает строку. Возьми весь текст в кавычки:
  `Пестик: "Женская часть цветка: рыльце, столбик, завязь."`
- Кавычки нужны и тогда, когда текст начинается с `-`, `[`, `{`, `#`, `*`, `&`, `!`, `|`, `>`, `%`, `@` или `` ` ``.
- Термин в одном наборе не может повторяться — приложение подскажет, какой.
- Длина: термин до 200 знаков, определение до 1000.

Если в файле ошибка, приложение покажет номер строки или название параграфа.

## Обновление набора

Исправь файл и загрузи его снова — с тем же `id` он заменит старую версию.
Карточки, которые уже лежат в стопках, при этом не меняются: в стопку добавятся только
новые термины. Чтобы получить исправленные определения, удали карточку в стопке и
загрузи параграф ещё раз, или исправь её вручную.
